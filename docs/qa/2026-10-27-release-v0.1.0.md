**Bugs**, worst first:
### [major] The real-screen release gate has not been run
- The README's own status table marks the F10 popup and the borderless/F11 mode "not yet seen on a screen", and a real pad "not yet tried". A v0.1.0 (non-alpha) release would ship those as features.
- Needs: a Windows PC with a monitor, Steam and the game, as a netlab machine (or a supervised manual run on the workstation).

### [minor] The installer fetches pcrecomp `main`, unpinned
- launcher/launcher.json: `"sources": [{"repo": "sp00nznet/pcrecomp", "ref": "main"}]`. A v0.1.0 installer gets whatever pcrecomp main is on the day it's run.
- Today that's a85ea97. The tester's regression built on 7f217a7, 6 commits behind (all win32hle changes, probably unused by native32, but untested).
- Expected: the release pins a pcrecomp commit.

### [minor] A CD install goes through the whole build with no warning
- The launcher looks up `HKLM\...\LucasArts...\Install Path`, a key a CD install has. Since 13d6236, setup step 3 takes an exe without SteamStub "as it is". It only prints "No SteamStub (not the Steam release)".
- Setup doesn't check for `Sdata\ddraw.dll` or the PE stamp. A v1.0 CD exe builds for 20 to 60 minutes, then sote.exe refuses it. A 1.1 install builds and then runs untested (no ddraw.dll, CD check).
- Expected: setup fails at step 3 with one sentence ("Steam copy needed; CD: issue #1").
- Not run: no CD copy exists here. Found by reading tools/setup.ps1 lines 166-193.

### [minor] Release paperwork for v0.1.0 isn't done
- The README status says "v0.1.0-alpha.1", and the CHANGELOG has only [Unreleased].

### [polish] Doc inconsistencies
- First build: README says "15 to 45 minutes", the installer note says "20 to 60 minutes".
- CHANGELOG 0.1.0-alpha.1 says it "needs pcrecomp `feat/steamstub-v3`". That's stale: pcrecomp#110 and #111 were merged 2026-10-19.
- README "Building from source" names `local/projects/shadows.env`. The recipe is `projects/shadows.env`.
- host.c's error now names "the 1.1 patch's" exe as accepted. A CD owner reads that as support.
